Autonomy metrics

Less prompting is useful only if competence survives.

Autonomy is measured against material work, not number of chat messages.

  1. Founder Prompt DependencyFresh non-reserved Founder directions required ÷ material institutional work items completed × 100.
  2. Founder RescueA Founder intervention needed because the system ignored or misapplied a rule, evidence source, authority boundary or control it already possessed.
  3. Autonomous CompletionA material work item completed within existing authority without fresh substantive Founder direction.
  4. Reserved Crown DecisionA matter that properly requires the Founder by constitution or external-action rule. It is tracked but does not count as dependency.

Admission rule

A real-world event is not automatically an Aldernian event.

Relevance must be demonstrated before an external stimulus enters the experiment.

REAL STATE / EVENT→AUTHORITATIVE SOURCE→MATERIAL RELEVANCE→COMPETENT INSTITUTION→INTERNAL ACTION→CHALLENGE→HUMAN GATE IF EXTERNAL→VERIFY→RECORD

No institution is instructed to produce a dramatic outcome. Most external news should never enter the log.

Runtime & confounders

The machinery can change the result.

Material changes to the LLM, model configuration, tool access, retrieval method, source estate, governance or execution environment must be logged because they may explain changes in behaviour.

The Genesis commissioning session used GPT-5.6 Sol. This is a runtime observation, not a claim that every future Aldernian action will use the same model.

Future entries record the date, what changed, why it changed and whether observed behaviour materially shifted afterward.
