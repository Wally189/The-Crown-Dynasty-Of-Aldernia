Accessibility

Accessibility grows with the country.

The website targets WCAG 2.2 AA design practice without claiming formal conformance before release-level testing.

The website uses semantic HTML, a skip link, keyboard-operable native navigation, visible focus indicators, responsive layouts, text rather than colour alone for meaning, no motion-dependent content and no essential JavaScript.

The current design uses a strengthened muted-text palette and sizes primary navigation controls above the WCAG 2.2 minimum pointer target threshold.

Exact-website keyboard, zoom/reflow, colour-contrast, focus-obscuration and accessibility-tree sampling are release acceptance checks. No independent accessibility audit or formal conformance claim is made by this page.
