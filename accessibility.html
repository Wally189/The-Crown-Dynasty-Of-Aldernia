Accessibility

Accessibility grows with the country.

The candidate targets WCAG 2.2 AA design practice without claiming formal conformance before release-level testing.

The candidate uses semantic HTML, a skip link, keyboard-operable native navigation, visible focus indicators, responsive layouts, text rather than colour alone for meaning, no motion-dependent content and no essential JavaScript.

The review corrected the production stylesheet’s muted text contrast issue in the candidate palette and sizes primary navigation controls above the WCAG 2.2 minimum pointer target threshold.

Before any production release, the exact build still requires keyboard testing, zoom/reflow checks, colour-contrast verification, screen-reader sampling and checks for focus being obscured by persistent interface elements. No independent accessibility audit has been performed.
