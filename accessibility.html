Accessibility baseline

The experiment should be observable without the right device, eyesight or dexterity.

Genesis approach

The surviving site is static HTML and CSS with ordinary links, semantic headings, visible focus treatment, scalable text, responsive layouts and reduced-motion support in the shared stylesheet.

The core Genesis record does not require JavaScript to read or navigate.

Limits

This is not a claim of independent WCAG conformance or assistive-technology certification. Material new interactions must be tested against the actual feature when they are introduced.

One truth

An accessible version must contain the same substantive evidence as any other presentation of the experiment.
