Accessibility

Public life should not require the right eyesight, device or dexterity.

Accessibility is part of Aldernian beauty, not a corrective skin applied after the interesting design work is finished.

Current public build

The site uses semantic HTML, keyboard-focusable controls, scalable text, visible focus, responsive layouts, reduced-motion support and high-contrast functional colour pairings.

Design commitment

Future media should provide captions and transcripts. Maps and charts should have equivalent text or data access. Election information should have plain-language and low-bandwidth routes. Major interactive controls are designed for generous target sizes.

What this is not

This page is a project commitment, not a claim that every future Aldernian feature has passed an independent accessibility audit or assistive-technology test. When the site gains materially new interactive services, those tests must be performed against the actual build.
