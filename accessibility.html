Accessibility

Public life should not require the right eyesight, device or dexterity.

This build uses semantic HTML, keyboard-focusable controls, scalable text, visible links, high contrast and responsive layouts. Interactive demonstrations do not require a mouse.

Future audio/video content should include captions and transcripts. Election information should have plain-language and low-bandwidth versions. Meaningful images should have text alternatives.

This page is a project commitment, not a claim that every future feature has already passed formal accessibility audit.
