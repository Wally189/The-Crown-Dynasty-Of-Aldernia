Public founding edition

Privacy by doing less.

This edition deliberately avoids features that would require collecting a visitor’s account data simply to make the site look more sophisticated.

What this edition does

The published pages use ordinary HTML, CSS and a small first-party script for the clocks, date context and build identity. The site does not intentionally set non-essential cookies, operate user accounts, collect form submissions, run advertising technology or embed third-party analytics in this founding edition.

Hosting

The site is hosted through GitHub Pages. As with any web host, GitHub may process technical request data under its own service operation and policies. Aldernia does not convert hosting logs into a fictional citizen register.

Future features

Accounts, comments, civic registration, analytics, payments, donations or personalised features are not silently covered by this notice. If any are introduced, the relevant UK/Irish legal, privacy, security, child-protection and transparency review must occur first and the public notice must be updated before launch.

Current regulatory research

The design has been checked against current public guidance including the UK ICO’s April 2026 storage/access technology guidance and Ireland’s Data Protection Commission cookie guidance. This page records the current design posture; it is not a claim that every possible future feature is pre-cleared.
